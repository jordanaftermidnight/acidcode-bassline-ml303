Manufacturing Notes

Design Specifications

  • Board Size: 12.7mm × 12.7mm (single adapter)
  • Min Trace Width: 0.254mm (10 mil)
  • Min Via Size: 0.3mm (12 mil)
  • Min Drill Size: 0.3mm
  • Pad Size: 1.8mm diameter with 0.9mm hole
  • Annular Ring: 0.15mm minimum

Ordering Tips

  • JLCPCB: Upload ZIP, select 2-layer, 1.6mm thickness
  • PCBWay: Use instant quote, select lead-free HASL
  • OSH Park: Purple PCBs, ENIG finish standard
  • Quantity: Order extras (minimum 5-10 extra)
