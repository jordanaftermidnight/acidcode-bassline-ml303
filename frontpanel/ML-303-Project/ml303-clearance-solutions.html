ML-303 Button Clearance Solutions

Problem Overview

Clearance Issue: The original Conrad 3-pin buttons are discontinued. Standard 4-pin tactile switches with adapters may not fit due to:
  • 40-pin PIC processor height (~15mm with socket)
  • LEDs on the main board (5-8mm)
  • Limited panel-to-PCB clearance
  • Other tall components (capacitors, crystal)

Two Solutions

Solution 1: Low-Profile Adapters

Specifications:

  • PCB Thickness: 0.8mm (vs standard 1.6mm)
  • Switch Type: 6mm or 7mm height tactile
  • Total Stack: ~8mm maximum
  • Connection: SMD traces, minimal vias
  • Manufacturing: Requires thin PCB option
✓ Pros:
  • Maintains original layout
  • No case modifications
  • Clean installation
  • Direct replacement
✗ Cons:
  • Still may not fit
  • Requires special PCB
  • Limited switch options
  • More expensive PCBs

Solution 2: Remote Mount Board

Specifications:

  • Board Size: 279.4 × 177.8mm (matches panel)
  • Connection: 40-pin ribbon cable
  • Switch Type: Any 12×12mm tactile
  • Features: Built-in pull-ups, matrix wiring
  • Mounting: Behind front panel
✓ Pros:
  • Guaranteed to fit
  • Use any switches
  • Easy debugging
  • Arduino integration
✗ Cons:
  • Requires ribbon cable
  • More complex assembly
  • Cable management
  • Larger PCB cost

Recommendations

Before Choosing:

  1. Measure First: Remove one Conrad switch and measure exact clearance
  2. Check Components: Identify tallest component on main board
  3. Test Fit: Try a standard tactile switch in the space

If Clearance < 10mm:

Go with Remote Mount Solution - it's guaranteed to work and provides most flexibility for future modifications.

If Clearance > 10mm:

Try Low-Profile Adapters first - simpler installation and maintains original design intent.
