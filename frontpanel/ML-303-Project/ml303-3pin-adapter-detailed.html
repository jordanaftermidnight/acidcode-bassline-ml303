ML-303 3-PIN TRIANGULAR ADAPTER

Problem & Solution Overview

⚠️ The ML-303 Button Problem

  • Original buttons: Conrad-exclusive 12x12mm switches with unique 3-pin triangular footprint
  • Status: DISCONTINUED - No direct replacements exist
  • Issue: Standard switches use 4-pin square layout, incompatible with ML-303 PCB
  • Solution: Custom adapter boards convert standard 4-pin to ML-303 3-pin layout

✅ Adapter Solution Benefits

  • Use widely available standard 12x12mm 4-pin switches
  • Maintains original 12-13mm button spacing
  • Minimal height addition (~2mm)
  • Can be built on stripboard or custom PCB
  • Cost: ~€0.50 per adapter vs €50+ for original switches

Building Instructions

Materials Needed (per adapter)

  • Stripboard piece: 5x5 holes (12.7mm × 12.7mm)
  • 30 AWG wire: ~10cm total (3 colors recommended)
  • Solder and flux
  • Track cutting tool or 3mm drill bit

Step-by-Step Assembly

  1. Cut stripboard: Use a sharp knife to cut 5x5 hole sections
  2. Make track cut: Break the copper track at position C3
  3. Prepare wires: Cut three 3cm pieces, strip 2mm from each end
  4. Solder switch side: Attach wires to positions matching 4-pin layout
  5. Route wires: Use angled routing for clean appearance
  6. Solder ML-303 side: Connect to triangular pad positions
  7. Test continuity: Verify connections with multimeter

Alternative Solutions

Option A: Individual Adapters (Recommended)

  • One adapter per button
  • Easy to troubleshoot
  • Can replace individual buttons
  • Slightly more work to build

Option B: Row/Matrix Adapters

  • One adapter per row of buttons
  • Faster to build
  • Cleaner wiring
  • Harder to troubleshoot individual buttons

Option C: Custom PCB

  • Professional solution
  • Order from PCB manufacturer
  • Perfect fit and reliability
  • Higher initial cost
