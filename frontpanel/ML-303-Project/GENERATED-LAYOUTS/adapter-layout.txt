Total components:
- BUTTON_12x12mm: 1

- WIRE_Bridge: 2

BUILD INSTRUCTIONS:
------------------
1. Cut stripboard to 4 rows x 10 columns

2. Make track cuts at:
   - A5
   - B5
   - C5
   - D5

3. Install components in this order:
   a) Wire jumpers
   b) Resistors
   c) Capacitors
   d) IC sockets
   e) Headers and connectors

4. Check all connections with multimeter
5. Install ICs last (after power test)
