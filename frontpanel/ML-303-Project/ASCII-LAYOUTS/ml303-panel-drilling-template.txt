DRILLING INSTRUCTIONS:
=====================
1. Print template at 100% scale (no scaling)
2. Verify dimensions with ruler
3. Tape template to panel
4. Center punch each [#] location
5. Drill pilot holes (3mm)
6. Use step drill or nibbler for square holes
7. File to exact 12mm x 12mm size

CLEARANCE NOTES:
===============
- Minimum 3mm clearance from panel edge
- 13mm spacing between button centers (minimum)
- Allow 2mm clearance for button caps
- Consider component height behind panel

ALTERNATE ROUND HOLE PATTERN:
============================
If square holes are too difficult:
- Drill 10mm round holes at each [#] center
- Buttons will still fit but may rotate
- Use button caps to hide gaps
